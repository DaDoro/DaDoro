## 👋 Привет

Мне 19, программирую с 11 лет: начинал с C# и Unity в школе программирования, сейчас в основном пишу на Python.

Обычно всё начинается с того, что мне или друзьям чего-то не хватает: удобного способа смотреть кино вместе, живого трафика на нашем сервере в Assetto Corsa, автоматических чеков для своего сервиса. Так появляются проекты, и некоторые из них дорастают до продуктов с живыми пользователями.

Код пишу в паре с Claude Code: архитектура, проверка и отладка на мне, рутину отдаю ИИ.
